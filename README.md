# Multiple Imputation for Missing-Not-At-Random Categorical Data Using Classification Trees

## Requirements

R with the packages `tidyverse`, `rpart`, and `here`:

```r
install.packages(c("tidyverse", "rpart", "here"))
```

## Setup

Open `mnarcart_supplementals.Rproj` in RStudio, then run the scripts in the
order below. All file paths are relative to the project folder. If you do not
use RStudio, set your working directory to this folder before running a script.

## Files and run order

| Order | File | Purpose |
|-------|------|---------|
| 1 | `section 4) simulation synthetic population creation.R` | Builds the synthetic population from the CPS and ANES data; writes `sim_pop.csv` |
| 2 | `section 4) mnarcart to simulation.R` | Runs the simulation study (Section 4) using `sim_pop.csv` |
| 3 | `section 5) mnarcart to realdata.R` | Applies the method to the ANES 2020 data (Section 5); writes to `results/` |

A pre-generated `sim_pop.csv` is included, so script 2 can be run without
running script 1.

## Data

- `oct20pub.csv.gz`: October 2020 CPS Basic Monthly public-use file (U.S.
  Census Bureau), gzip-compressed. R reads it directly; do not decompress it.
- `anes_timeseries_2020_csv_20220210.csv`: ANES 2020 Time Series Study
- `sim_pop.csv`: synthetic population generated by script 1.
